# DESIGN.MD
Metro Grill Restobar Rohini

## Design Vision
Create a digital experience that feels like stepping into an upscale hospitality destination.
The website should evoke the feeling of entering a premium restaurant lobby, not browsing a food delivery platform.

Every interaction should reinforce:
- Premium dining
- Social gatherings
- Celebration experiences
- Hospitality excellence
- Urban sophistication

The design must communicate confidence, atmosphere, and exclusivity.

## Core Design Principles

### Experience Before Information
Users should feel the atmosphere before they read the menu.

### Hospitality Over Technology
Technology should disappear into the background.
Avoid obvious "web design" patterns.

### Editorial Storytelling
Every section should read like a premium magazine feature rather than a corporate landing page.

### Content Density
Avoid empty luxury.
Premium does not mean large empty spaces with no information.
Every section should communicate value.

### Architectural Structure
Layouts should feel intentional and geometric.
No floating elements.
No random positioning.
No decorative clutter.

### Visual Personality
**Keywords:**
Sophisticated, Refined, Warm, Urban, Social, Contemporary, Premium, Atmospheric

**Avoid:**
Playful, Startup, Futuristic, Tech-inspired, Neon, Experimental

## Color System
- **Primary Background:** Warm Ivory `#F7F3ED`
- **Secondary Surface:** `#FFFFFF`
- **Primary Text:** `#111111`
- **Accent Bronze:** `#8A6A42`
- **Deep Espresso:** `#3D291A`
- **Muted Stone:** `#7A756F`
- **Border Color:** `#D8D2C8`

## Typography
### Display Font
**Cormorant Garamond**
- Font Weight: 500, 600
- Usage: Hero headlines, Section titles, Feature statements
- Characteristics: Elegant, Editorial, Luxury hospitality feel

### Body Font
**Satoshi**
- Weights: 400, 500, 700
- Usage: Navigation, Content, Buttons, Forms

### Typography Scale
- Hero: 96px - 120px
- Section Headings: 56px - 72px
- Sub Headings: 32px - 40px
- Body Large: 20px
- Body: 18px
- Caption: 14px

## Grid System
- Desktop: 12-column grid, 1440px container
- Tablet: 8-column grid
- Mobile: 4-column grid
- Maximum content width: 1280px

## Layout Philosophy
No stacked repetitive sections. Alternate rhythm continuously.
Example: Full width image -> Split layout -> Editorial layout -> Full width statement -> Gallery narrative -> Reservation section.
Avoid predictable patterns.

## Card Design Rules
- Border Radius: `0px`
- Always. No exceptions.
- Styling: Thin borders, minimal shadows, sharp corners, structured spacing.
- Cards should resemble premium menu covers, not SaaS feature cards.

## Image Treatment
Photography is the hero. Images must occupy significant visual weight.
- Use: Full-screen imagery, Large landscape compositions, Immersive crop styles, Editorial framing
- Avoid: Tiny thumbnails, Uniform gallery grids, Circular images

## Motion System
Animation Philosophy: Invisible luxury. Users should feel motion, not notice motion.
- Allowed Animations: Image masking, Cinematic reveals, Horizontal transitions, Scroll-linked movement, Layer depth shifts, Typography sequencing
- Forbidden Animations: Bounce, Zoom pop, Elastic effects, Spinning elements, Flashing effects, Generic fade-up

## Component Specifics

### Navigation
Transparent over hero. Transforms on scroll. Minimal. Elegant. No oversized buttons. No glassmorphism.

### Hero Section
- Height: `100vh`
- Content Position: Bottom-left alignment
- Visual: Full-screen cinematic restaurant imagery
- Overlay: Subtle dark gradient
- Content: Location Tag, Large Headline, Supporting Statement, Reservation CTA

### Signature Dishes Section
Not a card grid. Use editorial storytelling. Large image, chef note, dish narrative, ingredient highlights.

### Celebration Experiences Section
Feature Birthdays, Family Gatherings, Corporate Events, Weekend Dining.
Presented as large immersive content blocks. Not icon cards.

### Testimonial System
Avoid sliders, avoid rotating testimonials. Use editorial quote walls, highlighted customer stories, integrated photography.

### Reservation Experience
Should feel premium. Include reservation date, guest count, occasion type, preferred seating. Prominently display Call, WhatsApp, Table Booking.

### Footer
Large and content-rich. Restaurant Story, Opening Hours, Location, Contact, Reservations, Social Media, Map.
